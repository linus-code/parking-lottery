# 车位摇号 · 号码推算

一个单文件网页工具：根据三只 A 股（600690 海尔智家 / 688139 海尔生物 / 300143 盈康生命）的收盘价，
推算在「整体百万环形」摇号规则下期望距离最小的 6 位号码。

> **它不预测股价。** 详见 [方案与对抗性审查.md](./方案与对抗性审查.md)。

在线版：<https://linus-code.github.io/parking-lottery/>

## 规则

1. 取三只股票开奖日收盘价的小数点后两位，各自反转（`19.69 → 96`）
2. 按 600690 / 688139 / 300143 顺序拼成 6 位数（`96 + 96 + 37 = 969637`）
3. 候选人号码与该数的**环形距离**（0–999,999 首尾相接）最小者中签

## 为什么存在可利用的优势

中签是**排名**问题，不是全等匹配 —— 所以问题不是「猜中百万分之一」，而是
「在环形上尽量靠近高概率区域」。

而 A 股收盘价的**分位（百分位）**存在显著且稳定的聚集：

| 股票 | 样本 | 分位 = 0 频率 | 卡方 (df=9) |
|---|---|---|---|
| 海尔智家 | 3,031 | 14.3% | 100.6 |
| 海尔生物 | 1,684 | 19.8% | 200.1 |
| 盈康生命 | 2,773 | 15.4% | 113.7 |

（99% 临界值 21.67；十分位基本均匀且与分位独立）

这使派生号落在 `000000–099999` 区间的概率比均匀分布高约 43%，
最优号码因此稳定落在 `03–05 万` 区间。

## 效果（样本外验证）

只用切点之前的历史选号，在切点之后的真实开奖数据上测命中率：

| 训练截止 | 训练/测试天数 | 选出号码 | 命中率 (±83,333) | 均匀基准 | 倍数 |
|---|---|---|---|---|---|
| 2023-01-02 | 774 / 908 | 045118 | 19.60% | 8.33% | 2.35× |
| 2024-01-02 | 1016 / 666 | 044659 | 19.82% | 8.33% | 2.38× |
| 2025-01-02 | 1251 / 431 | 035026 | 19.72% | 8.33% | 2.37× |

6 组测试全部为正、无符号翻转。但每次选出的号码不同 ——
**大方向稳健，具体号码在噪声以内。**

块自助重采样 300 次：最优号 **85.7% 落在 0–10 万带内**，
但只有 **18.3% 落在单点 ±5,000 内**。所以页面上给的是
「稳健区间 `024141 – 061547`」而不是一个孤零零的号码。

## 使用

直接用浏览器打开 `index.html` 即可，无需服务器、无需安装。

- 实时行情来自腾讯（`qt.gtimg.cn`，CORS `*`）+ 东方财富，双源交叉校验
- 接口失败时回落到内置基准价，仍可离线使用
- 参数（参与人数 / 车位数）可调，中签率实时重算

## 算法

```
E[d(n)] = Σ_x P(x) · min(|n − x|, 1000000 − |n − x|)
```

P(x) 由三只股票末两位的边际分布因子化得到（20 参数/股）。
对全部 100 万个 n 求 E，用 **3 倍长度前缀和** 在 O(N) 内完成，前端实时计算（约 29ms）。
与 FFT 卷积对拍，最大相对偏差 `1.25e-5`。

## 已知局限

- **反身性**：如果所有人都用这个工具，优势会退化为并列
- **单一统计量依赖**：优势主要来自 600690 分位 = 0 的频率，建议每季度重训
- **规则口径**：若实际是「逐位环形」而非「整体百万环形」，全部结论作废
- **并列排序**：环形距离相同时如何分先后，规则未定义
